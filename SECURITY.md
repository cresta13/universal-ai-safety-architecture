# Security

Do not post secrets, credentials, exploit-enabling details, personal data, or confidential vendor information in public issues.

If GitHub private vulnerability reporting is enabled for this repository, use that channel for sensitive safety or security reports. Otherwise, contact the repository owner through an available private channel listed on the author's public profile.

Public issues are appropriate for non-sensitive conceptual safety problems, terminology issues, standards overlap, measurement concerns, and review comments that do not enable harm.

AIVE is a proposed architecture, not yet an operational vulnerability registry.
