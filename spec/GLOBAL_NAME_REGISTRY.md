# Global Name Registry

Normative identifiers are globally unique semantic `UpperCamelCase` names. Optional aliases are prose-only. Uniqueness is evaluated after lowercasing and removing whitespace, underscores, hyphens, periods and punctuation; namespaces do not resolve collisions. `AI` is reserved for Artificial Intelligence and `UAIS` for this standards family.

## Migration rule

Previous identifiers support migration of existing implementations only. Draft 1.0 Candidate tables, schemas, payloads, traceability and machine-readable examples use the Normative Identifier. Display codes such as H0–H5, P0–P5 and S0–S5 remain consumer/class values rather than object identifiers.
