# Готовность русской веб-книги UAIS к будущим переводам

Статус этапа 1: опубликована только локаль `ru`. Английская, китайская, испанская и арабская версии не созданы, не сгенерированы и не показаны пользователю как доступные.

## Где находится текст

Основной пользовательский текст хранится в `docs/data/ru-content.json`.

Файл содержит:

- `locale` и `dir`;
- русские UI-строки в `ui`;
- список будущих локалей в `futureLocales` со статусом `planned`;
- метаданные страницы и PDF в `meta`;
- все 20 листов книги в `pages`;
- терминологию в `terms`.

HTML и JavaScript не содержат содержательных листов книги. Они только загружают JSON и строят DOM-страницы.

## Как добавить новую локаль после утверждения русской версии

1. Создать отдельный файл данных рядом с русским, например `docs/data/en-content.json`.
2. Сохранить те же `id`, `slug`, `layout`, `terms` и структуру `notes`.
3. Перевести `meta`, `ui`, `pages[*].title`, `subtitle`, `kicker`, `lead`, `notes` и `terms`.
4. Для арабского файла выставить `dir: "rtl"`.
5. Добавить реальный переключатель локали только после проверки готового файла, PDF и прямых ссылок.
6. Выпустить отдельный PDF для каждой утверждённой локали.

## Компоненты, чувствительные к длине текста

- `sheet-cover`: крупный заголовок и главный тезис.
- `sheet-principles`: десять принципов, особенно длинные формулировки 5, 8, 9 и 10.
- `sheet-guardian`: центральный блок `ВИДЕТЬ ≠ ДЕЙСТВОВАТЬ` и две колонки заметок.
- `sheet-example`: сквозной пример с длинными шагами и денежными лимитами.
- `sheet-glossary`: полный технический глоссарий, где русский термин должен быть крупнее английского canonical label.
- `toc-list`: список всех листов.
- `note-title`: заголовки заметок с длинными терминами.
- PDF-генератор `scripts/generate_pdf.py`: перенос строк и высота заметок.

## Шрифты для будущих языков

- `en`: текущие системные sans-serif шрифты достаточны.
- `es`: текущие шрифты должны покрывать латиницу с диакритикой.
- `zh-Hans`: потребуется CJK-шрифт для сайта и PDF, например Noto Sans SC.
- `ar`: потребуется арабский шрифт и проверка shaping/RTL в браузере и PDF, например Noto Naskh Arabic или Noto Sans Arabic.

## Что повторно проверить перед включением переключателя языков

- Нет ли baked-in текста в PNG/JPG.
- Все `slug` стабильны и не ломают старые прямые ссылки.
- Работает `dir="rtl"` для арабской версии.
- Длинные переводы не накладываются на tape, заметки, стрелки и соседние блоки.
- PDF каждой локали содержит встроенные шрифты и корректные переносы.
- Open Graph и canonical URL не вводят пользователя в заблуждение.
- Переключатель показывает только реально готовые и утверждённые языки.

## Осознанное ограничение

Будущие локали перечислены только как конфигурация планируемой архитектуры. Пользовательский интерфейс этапа 1 не показывает активный выбор языка.
