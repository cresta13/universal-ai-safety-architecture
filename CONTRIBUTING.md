# Contributing

UAIS is currently a Draft 1.0 Candidate for public review. Contributions are reviewed as technical input to a pre-standard research architecture.

## What feedback is most useful

- conceptual counterexample;
- unsafe edge case;
- formal inconsistency;
- undefined term;
- measurement problem;
- metric gaming path;
- correlated-evaluator failure;
- implementation impossibility;
- prior art;
- standards overlap;
- privacy issue;
- governance capture problem;
- real-world use case;
- reference implementation.

## What not to submit publicly

- credentials;
- real exploit secrets;
- dangerous attack-enabling details;
- personal data;
- confidential vendor information.

## Contribution status

Submission of an issue or pull request does not imply acceptance into the normative architecture.
