# Changelog

## 1.0.0-candidate.2 — 2026-08-25

Corrective public-review prerelease.

Includes:
- corrected public architecture flow from capability request to Capability Boundary, bounded authorized envelope, Consequence Interface, and digital/physical consequence;
- canonical Capability Boundary terminology while preserving Novel Capability Gate as the special unknown-capability mechanism;
- actor-agnostic / not actor-blind clarification;
- Trustworthiness formal closure for no-rating/null state, separate status/rating fields, Not Applicable evidence rules, and scoring-policy mandatory fields;
- SEP restored as StructuredEvidencePackage, with SafetyEvidencePath as an internal or referenced provenance chain;
- metric and open-research boilerplate reduced with trustworthiness-specific metrology and research-card content;
- GitHub Pages public explainer corrected for links, semantics, principles, Stage I/II, non-claims, reporting, independent evaluation, and no-averaging critical-error rule;
- roadmap, known limitations, contribution notice, citation metadata, and Master Index baseline updated.

This remains a public-review pre-standard candidate, not a final or adopted standard.
